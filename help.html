Find your credentials

You need a Team ID and a management key from the xAI console. Do not use an API key.

Open Settings

Sign in, then click the gear at the bottom left, next to Credits. console.x.ai

Copy the Team ID

In Settings, under Team, click General. Copy the Team ID on that page. It is the long value with dashes. Open Settings

Create a management key

Click Management keys, then Create management key. Set Billing to Read only. Leave Allowed IP Address empty. Copy the key while it is on screen. It is shown once. Open Management keys
